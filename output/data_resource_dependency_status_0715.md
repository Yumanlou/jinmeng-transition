## 二、模型设定

### 1. 2012 年全国政策与资源依赖

\[
Y_{it}=\beta_1(Post2012_t\times CoalExposure_i)
+\beta_2(Post2012_t\times ResourceDependence_i)
+\beta_3(Post2012_t\times CoalExposure_i\times ResourceDependence_i)
+\gamma X_{it}+\mu_i+\lambda_t+\varepsilon_{it}.
\]

`CoalExposure x ResourceDependence` 是省份层面不随时间变化的低阶交互，被省份固定效应吸收。新能源结果由于缺少 2012 年前数据，改用 2016 年断点。

### 2. 2017 年首批试验区补充模型

\[
Y_{it}=\theta_1(Pilot_i\times Post2017_t)
+\theta_2(Post2017_t\times ResourceDependence_i)
+\theta_3(Pilot_i\times Post2017_t\times ResourceDependence_i)
+\gamma X_{it}+\mu_i+\lambda_t+\varepsilon_{it}.
\]

试验区实际为五省区内的城市或新区，省级编码是近似，且试点落点非随机，因此该模型只是补充证据。

### 3. 分维度与早期外送条件

就业依赖、煤炭资产依赖、资源税依赖、国有工业资产锁定和采矿业财政依赖分别标准化后进入同一低阶交互完整的DDD模型。另以2016年为断点，用2015年早期外送近似指标检验外送条件是否放大高煤炭地区的新能源替代。

## 三、当前结果

### 1. 2012 年资源依赖 DDD

- 政策后煤炭暴露对五类能源强度和煤炭终端强度的系数分别为 `-0.2996`（`p=0.0487`）和 `-0.4641`（`p=0.0001`）。
- 资源依赖三重交互对能源强度、煤炭强度和煤炭占比均不显著，尚不支持“资源依赖使强度压降失效”。
- 三重交互对工业二氧化硫为 `-28.6690`（`p=0.0851`），对氮氧化物为 `-38.8085`（`p=0.0309`），说明资源依赖更可能把政策反应集中到污染治理。
- 三重交互对二氧化碳、火电装机占比和火电发电占比均不显著，不支持资源依赖地区已发生稳定的深层结构调整。
- 2016 年断点下，三重交互对风光发电占比为 `-0.1437`（`p=0.0516`），表明资源依赖越深，高煤炭暴露地区后期越难形成风光发电替代。

### 2. 2017 年首批试验区补充模型

- 资源依赖三重交互对 `ln(CO2)` 为 `0.2290`（`p=0.0024`）。
- 资源依赖三重交互对火电发电占比为 `0.0434`（`p=0.0182`）。
- 对能源强度、煤炭占比和风光发电占比的三重交互不显著。

这组结果的安全表述是：资源依赖不一定削弱绿色金融的所有效果，但它可能将政策效果锁定在高煤炭体系内部的污染治理，并阻碍其向风光替代、碳排放路径和火电结构调整延伸。

### 3. 新增分维度结果

- 国有工业资产锁定的三重交互对五类能源强度为 `-0.3796`（`p=0.0189`），对煤炭占比为 `0.1990`（`p=0.0044`）。这表明国有工业资产占比较高的高煤炭地区可以出现更强的强度压降，但煤炭占比下降受到明显抵消。
- 采矿业财政依赖的三重交互对工业二氧化硫为 `-39.0277`（`p=0.0070`），对氮氧化物为 `-42.0989`（`p=0.0074`），对工业固废不显著。
- 采矿业财政依赖的三重交互对煤炭占比、二氧化碳、火电装机和风光发电均不显著。财政依赖的证据集中在污染治理，而非结构退出。
- 2015年早期外送条件的三重交互对火电装机、火电发电、风电装机、风电发电和风光发电均不显著，不能据此声称外送条件显著强化结构替代。

### 4. 消纳约束的后验描述

- 2020-2023年省级平均弃风率与政策前资源依赖指数的相关系数为 `0.522`，与采矿业财政依赖的相关系数为 `0.563`。
- 对省级平均弃光率，两项相关系数分别只有 `0.119` 和 `0.134`。
- 山西2020-2023年平均弃风率约为 `2.08%`，内蒙古按蒙西、蒙东非加权合并后约为 `5.98%`；内蒙古内部的蒙西和蒙东差异较大，应在案例展示中保留分区结果。

这些相关性只刻画政策后的消纳表现，不能进入2012年连续DID的因果识别，也不能证明资源依赖导致弃风。它们适合作为资源依赖与风电消纳约束相伴出现的附录证据。

## 四、仍缺数据

1. **可追溯的省级绿色信贷强度。** 现有 `gf_index`、`credit`等列没有原始工作簿、标签和公式，不应作为新主线的核心变量。Wind EDB 也未找到可扩展到全国的省级绿色贷款余额序列。
2. **煤炭专属财政收入。** 已补采矿业税收/GDP，但采矿业还包括非煤矿业；全国可比的煤炭相关税费和财政收入占比仍未找到。
3. **更早期的电网消纳条件。** 已补2015年后输出电量、2018年后风光利用小时和2020-2023年弃风弃光率，但特高压通道和2012年前外送能力仍未形成全国长面板。
4. **地方银行结构与煤电长期投资。** 国有工业资产占比已经补齐，省级银行竞争、煤电企业贷款和煤电长期资本存量仍缺。

## 五、可使用的论文方向

目前数据更适合支持以下命题：

> 资源依赖如何改变绿色金融的作用层级：它未必阻止强度压降和污染治理，但可能将政策反应锁定在存量高煤炭体系内部，并限制其向能源结构替代延伸。

比“资源依赖削弱绿色金融的有效性”更准确的标题是：

> **资源依赖与绿色金融的作用边界：从污染治理到结构替代**
