# 绿色信贷工具变量评估与实测结果（2026-07-16）

## 一、识别对象

需要识别的不是2012年政策冲击本身，而是省级绿色信贷代理对治理结果的因果效应。由于资源依赖异质性模型同时包含绿色信贷代理及其与政策前资源依赖的交互项，两项都可能内生，因此必须同时工具化：

\[
\begin{aligned}
Y_{it}={}&\beta_1 GreenCredit_{it}
+\beta_2 GreenCredit_{it}\times ResourceDependence_i\\
&+\gamma X_{it}+\mu_i+\lambda_t+\varepsilon_{it}.
\end{aligned}
\]

若基础工具为 \(Z_{it}\)，排除工具至少应包括 \(Z_{it}\) 和 \(Z_{it}\times ResourceDependence_i\)。只工具化绿色信贷代理而把交互项当作外生变量，会低估模型的内生性问题。

## 二、已实现的行业融资 shift-share

### 构造

1. 从绿色信贷工作簿提取31省、2007—2022年的工业利息费用及六个高耗能行业利息费用。
2. 使用2007—2011年数据固定各省六行业融资暴露权重。
3. 对每个省份，计算剔除本省后的全国六行业利息费用占工业利息费用的变化。
4. 用政策前固定暴露加权全国行业融资变化，并反向处理，使工具值越高代表高耗能行业融资相对收缩越强。
5. 同时构造相对变化和份额水平变化两种工具，并分别与政策前资源依赖交互。

主工具可写为：

\[
Z_{it}=-\sum_k s_{ik,2007-2011}
\left(\frac{Share^{-i}_{kt}}{Share^{-i}_{k,2007-2011}}-1\right).
\]

其中，\(s_{ik,2007-2011}\) 是省份 \(i\) 对高耗能行业 \(k\) 的政策前融资暴露，\(Share^{-i}_{kt}\) 是剔除本省后该行业在全国工业利息费用中的份额。

### 第一阶段

| 工具设定 | 内生变量 | 排除工具联合F | p值 |
|---|---|---:|---:|
| 相对变化 | 绿色信贷代理 | 2.9299 | 0.0694 |
| 相对变化 | 绿色信贷代理×资源依赖 | 2.0310 | 0.1495 |
| 相对变化，剔除2017年 | 绿色信贷代理 | 2.8281 | 0.0755 |
| 相对变化，剔除2017年 | 绿色信贷代理×资源依赖 | 1.7465 | 0.1922 |
| 份额水平变化 | 绿色信贷代理 | 1.1613 | 0.3272 |
| 份额水平变化 | 绿色信贷代理×资源依赖 | 1.1764 | 0.3227 |

不同结果变量样本下，Kleibergen--Paap rk Wald F介于0.0176和1.7325之间，远不足以排除弱工具问题。2SLS系数大幅波动、标准误明显膨胀，能源强度、煤炭强度、工业二氧化硫、煤炭占比、碳排放和火电结构均无稳定显著结果。风光发电占比在个别设定中显著，但对应的Kleibergen--Paap F仍低于2，不能解释为因果效应。

### 排除限制

即使第一阶段更强，该工具仍有理论风险：全国高耗能行业的融资变化可能通过行业需求、价格、产量和技术周期直接影响本省能源消费与污染排放，不一定只通过省级绿色信贷代理起作用。因此，这个行业融资shift-share只能作为探索性诊断，不能进入正文充当主因果识别。

## 三、推荐的银行网络 shift-share

更有希望的工具是：政策前省份银行网络权重乘以银行层面的全国绿色贷款冲击。

\[
BankIV_{it}=\sum_b BranchShare_{ib,2011}
\left(GreenLoanShare_{bt}-\overline{GreenLoanShare}_t\right).
\]

其中，\(BranchShare_{ib,2011}\) 是2011年银行 \(b\) 在省份 \(i\) 的网点份额；\(GreenLoanShare_{bt}\) 是该银行全国绿色贷款余额占客户贷款总额的比例。年份均值被扣除，省份和年份固定效应下依靠各地政策前银行网络与银行绿色转型差异识别。

当前已经通过Wind补齐：

- 工商银行、农业银行、中国银行、建设银行和交通银行2012—2022年的绿色贷款余额与客户贷款总额，55个银行年完整观测。
- 邮储银行客户贷款总额覆盖2012—2022年，但绿色贷款余额在2012—2015年缺失，因此只适合2016年后的扩展样本。
- 银行年度冲击文件已计算绿色贷款占比及年度变化。

仍缺的关键底表是2011年前后的“省份×银行”分支机构数量或贷款份额。监管部门的金融许可证查询可以提供机构名称、所在地和发证日期，但若只保留当前有效许可证，会产生历史网点的存续偏差。更稳妥的来源是包含设立、撤销和状态记录的历史银行分支数据库，再汇总为31省×5家银行的政策前权重。

银行网络工具仍需满足以下检查：

1. 第一阶段同时报告两个内生变量的Sanderson--Windmeijer条件F和整体Kleibergen--Paap F。
2. 控制“政策前银行权重×银行总贷款增长”，将绿色贷款结构冲击与一般信贷扩张区分开。
3. 检验政策前银行网络权重与结果变量政策前趋势是否相关。
4. 分别使用网点数量权重、存贷款权重和剔除本省后的银行冲击。
5. 由于只有五家长期披露银行，冲击数量偏少；应继续扩充银行样本，或采用弱工具稳健的Anderson--Rubin置信区间。

## 四、不建议使用的候选

| 候选工具 | 不建议原因 |
|---|---|
| 政策后×政策前高耗能产业占比 | 高耗能产业基础直接影响能耗、污染和结构结果，排除限制不成立 |
| 政策后×政策前贷存比或贷款/GDP | 一般信贷供给会直接影响投资、产出和能源需求 |
| 2017年绿色金融改革试验区 | 试点本身会直接影响地方绿色项目与治理，而且试点选择并非随机 |
| 政策文本词频 | 属于政策后的地方响应，可能直接影响结果，是后定变量 |
| 风光资源、火电基础或煤炭资源 | 直接决定能源结构和污染排放，更适合做异质性变量或控制变量 |
| 省际绿色信贷代理均值 | 可能反映共同产业周期、区域污染治理和空间溢出，排除限制薄弱 |

## 五、结论

现有数据能够构造的行业融资shift-share在统计上是弱工具，在理论上也缺乏可靠的排除限制，不能把当前相关结果升级为因果结论。下一步唯一值得继续投入的是银行网络shift-share：银行年度绿色贷款冲击已经获得，剩余任务是补齐2011年省份银行网点权重。只有该工具通过第一阶段、政策前趋势和排除限制检查后，才适合将绿色信贷代理的结果表述为因果效应。
