# 竞争性解释排除矩阵

## 总体判断

现有数据适合采用“结果模式匹配 + 针对性反证”的论证方式，但不足以宣称排除了所有竞争性解释。最稳妥的结论是：2012 年后，高煤炭暴露地区出现了具有煤炭针对性的强度压降与能源使用结构调整；这一模式不能由一般经济收缩、非煤能源同步下降、政策前工业结构、煤炭生产依赖或普通信贷深度单独解释。现有设计仍不能把这些变化唯一归因于绿色信贷，差异趋势、均值回归、同期污染治理政策和未经验证的银行传导渠道仍是实质性识别威胁。

## 证据矩阵

| 竞争性解释 | 针对性检验 | 关键结果 | 判断 |
|---|---|---|---|
| 一般经济收缩 | 以 GDP 增速、第二产业增加值增速和总发电量增速为安慰剂结果 | 系数分别为 -0.0177（p=0.540）、-0.0448（p=0.351）和 -0.0260（p=0.631） | 可以较明显削弱 |
| 纯粹的 GDP 分母效应 | 改用五类能源终端消费量和煤炭终端消费量的反双曲正弦值 | 五类能源消费量系数为 -0.6134（p<0.001）；煤炭消费量为 -0.8495（p=0.056） | 可以削弱，但煤炭实物量证据处于边界显著 |
| 所有能源同步收缩 | 比较煤炭与非煤终端消费量 | 非煤终端消费量系数为 -0.0332（p=0.798），煤炭终端消费量下降更明显 | 可以较明显削弱；结果更接近煤炭针对性调整 |
| 政策前工业结构 | 同时控制政策后×政策前第二产业占比、国有工业资产占比 | 能源强度、煤炭强度和煤炭占比的核心系数方向与显著性保持 | 不能单独解释核心能源结果 |
| 资源生产与资源依赖 | 同时控制政策后×煤炭产量占比、政策后×资源依赖 | 核心能源结果保持；组合模型中能源强度 -0.6048（p=0.003）、煤炭强度 -0.6227（p<0.001）、煤炭占比 -0.3033（p=0.028） | 不能单独解释核心能源结果 |
| 普通信贷深度 | 控制政策后×政策前贷款/GDP，并检验煤炭暴露×银行依赖的三重交互 | 核心能源结果保持，但银行依赖三重交互对能源强度和煤炭强度不显著 | 普通信贷深度不是主要混淆项；绿色信贷传导渠道未得到验证 |
| 同期大气污染治理 | 控制 2013 年后×政策前 SO2 基数，并加入 2016 年后×煤炭生产依赖 | SO2 系数降至 -6.5649（p=0.694），NOx 降至 -17.3646（p=0.380）；工业固废仍为 -71.6516（p=0.013） | SO2、NOx 无法与同期环保政策清楚分离；固废结果更稳 |
| 2016 年供给侧改革 | 将样本截断至 2015 年 | 能源强度 -0.3365（p<0.001）、煤炭强度 -0.3061（p<0.001）；煤炭占比与 SO2 不显著 | 不能解释早期强度压降，但可能参与后期煤炭占比和污染变化 |
| 差异趋势与均值回归 | 加入省份线性趋势，并结合连续暴露度事件研究 | 能源强度仅边界显著（p=0.061）；煤炭强度和煤炭占比不显著；SO2 变为正且显著。原事件研究中能源和煤炭强度也存在政策前趋势问题 | 无法排除，是当前最重要的识别威胁 |
| 能源暴露度定义驱动 | 用政策前火电占比、煤炭产量占比等替代政策前煤炭消费占比 | 替代暴露度通常不能复制主结果 | 结果依赖煤炭消费暴露度定义；既可体现消费端针对性，也构成稳健性风险 |
| 绿色信贷银行渠道 | 银行依赖三重交互、直接绿色信贷代理变量响应和结果关联 | 三重交互多数不显著，煤炭占比三重交互反而为正；直接绿色信贷代理变量此前也未形成稳定链条 | 无法验证，不宜把 DID 系数直接称为绿色信贷的独立因果效应 |

## 推荐论证层级

### 可以作为主结论

2012 年后，高煤炭暴露地区出现了具有煤炭针对性的能源强度和煤炭强度压降。该结果并非由 GDP 或第二产业整体收缩、总发电量下降、非煤能源同步减少、政策前工业结构、资源生产依赖和普通信贷深度单独驱动。

### 需要收缩的结论

污染治理证据应分项表述。工业固废结果在竞争性控制后仍较稳，SO2 和 NOx 则与政策前污染基数及 2013 年后的大气污染治理高度重合，不能作为绿色信贷独立作用的强证据。

### 不能由现有数据得出的结论

现有结果不能证明绿色信贷是上述变化的唯一原因，也不能证明银行绿色信贷供给构成了实际传导渠道。省份差异趋势、均值回归、同期环境和能源政策仍未被完全排除。

## 论文中的建议表述

本文不以穷尽所有替代机制为识别标准，而是检验绿色信贷解释能否产生一组区别于竞争性解释的可观察结果。结果显示，高煤炭暴露地区的变化集中于煤炭及总体能源投入，未伴随 GDP、第二产业产出、总发电量或非煤能源消费的同步收缩；在控制政策前工业结构、资源生产依赖和普通信贷深度后，能源强度、煤炭强度与煤炭占比结果仍然存在。这些结果削弱了普遍经济下行和静态资源差异的解释。不过，省份差异趋势会明显削弱主要系数，SO2 和 NOx 结果也无法与同期大气污染治理政策清楚分离，银行依赖和直接绿色信贷指标尚未验证金融传导渠道。因此，本文识别的是 2012 年后高煤炭地区具有煤炭针对性的约束性调整模式，并将其解释为与绿色信贷约束相一致的证据，而不将其表述为已排除所有同期政策后的单一政策因果效应。
